ESP32 CYD · 24H NETWORK MONITOR

Internet Monitor

Web installer · Choose the display controller fitted to your board.

Connect your ESP32 CYD using a USB data cable. Open this page in Chrome or Edge on your computer. Select the correct driver, choose the serial port and follow the installation prompts.

ILI9341

For boards with the ILI9341 display controller.

Use Chrome or Edge with Web Serial.

ST7789

For boards with the ST7789 display controller.

Use Chrome or Edge with Web Serial.

Installation may erase existing settings. After flashing, follow the on-screen Wi-Fi setup if prompted. Use a FAT32 microSD for logging on supported firmware.
